  名前説明

(ICollectionKeyValuePairString, Objectから継承)

ICollectionT が読み取り専用かどうかを示す値を取得します。
(ICollectionKeyValuePairString, Objectから継承)

(IDictionaryString, Objectから継承)
Keys
ICollectionT のキーを保持している IDictionaryTKey, TValue を取得します。
(IDictionaryString, Objectから継承)
Values
ICollectionT 内の値を格納している IDictionaryTKey, TValue を取得します。
(IDictionaryString, Objectから継承)
